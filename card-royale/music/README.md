# Card Royale music

Card Royale plays two songs from this folder:

| File | When it plays |
|---|---|
| `menu.mp3` | Anywhere in the menus (Battle tab, cards, shop, searching for a battle) |
| `battle1.mp3` | Only during a battle, from the VS screen to the result |

Put the two files here with exactly these names. They stream, so any length works, and each one loops.
Until a file is here, that song is silent and the game works as before. Players can turn the music off in
Settings (separate from sound effects).

GitHub refuses single files over 100 MB, so keep each song under that.

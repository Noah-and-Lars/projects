# Island Front: raw model uploads

Raw Sketchfab downloads as uploaded, kept here for safe keeping and re-packing.
The game uses the packed copies in `havoc-bay/front/models/` on `claude/island-front-rework`.
Each folder is one model; the eight-character prefix on each file is the upload id.
Licences are in each model's `license.txt` (inside its zip where zipped).

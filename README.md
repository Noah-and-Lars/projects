# projects

**The Arcade**: browser games that run straight from this repo, no installs.

Open `index.html` to browse the games, or turn on GitHub Pages to put the arcade online.
The Chat tab (`chat.html`) is a global chat for everyone on the arcade; messages are kept only in each player's browser.

## Games

| Game | Type | Controls |
|---|---|---|
| [Cube Assault](cube-assault/) | 3D shooter | Keyboard + mouse or touch |
| [Blocktris](block-drop/) | Falling-block puzzle | Keyboard or touch |
| [2048](2048/) | Sliding-number puzzle | Keyboard or swipe |
| [Poly Racer](poly-racer/) | 3D time-trial racing | Keyboard or touch |
| [Free Criminal](free-criminal/) | Open-world crime | Keyboard + mouse |
| [Cube Tower Defense](cube-tower-defense/) | Tower defense | Mouse or touch |
| [Blockcraft](blockcraft/) | 3D block sandbox with the Nether, the End and a public multiplayer server (survival and creative) | Keyboard + mouse or touch |
| [Russian Roulette](russian-roulette/) | First-person thriller | Mouse, keyboard or touch |
| [Chess](chess/) | Chess against the computer (Easy, Medium, Hard) | Mouse or touch |
| [Stocks Game](bull-run/) | Stock-trading strategy | Mouse, keyboard or touch |
| [Havoc Bay](havoc-bay/) | Red vs Blue sea battle with warships, planes and islands, online or against bots | Keyboard + mouse or touch |

## Adding a game

1. Make a folder with the game's `index.html` and a `thumb.svg` (or `.png`) cover.
2. Add one entry for it in `games.js`.

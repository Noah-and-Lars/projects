# Wrecking Shift

An original first-person voxel-destruction heist game for the browser. You are a freelance demolition contractor
taking odd jobs around Gullwick Harbour: plan a route through a fully destructible world, then grab the goods and
get back to the van before Harbour Watch arrives.

Everything is made of 10 cm voxels with material rules (wood/plaster/glass break with a hammer, brick and sheet
metal need guns or vehicles, concrete and steel need explosives). Cut pieces become rigid bodies, supports that are
whittled down get crushed by the load above, fire spreads and burns structures through, vehicles ram walls.

Tech: TypeScript, Vite, three.js (WebGL2), Rapier physics (native voxel colliders). No external art or audio
assets — levels, models, sounds and music are all generated by code.

## Run
```
npm install
npm run dev      # dev server (open the printed URL)
npm run build    # static build in dist/ (relative paths; host anywhere)
npm test         # typecheck + unit/sim tests (Node) + build + headless browser tests
```
URL parameters: `?mission=<id>` (e.g. `paper-trail`), `?sandbox=<level>` (`harbor`, `testyard`, ...),
`?level=<level>` free roam, `?test=1` test mode (no render loop; drive with `window.__game`).

## Controls
| Key | Action |
|---|---|
| WASD / mouse | move / look (click the view to capture the mouse) |
| Space, Ctrl or C, Shift | jump, crouch, sprint |
| LMB | use tool · RMB hold: grab an object (wheel = distance, LMB = throw) |
| 1–0, mouse wheel, Q | select tool |
| E | interact: take targets/valuables, enter/exit vehicles, clock out at the escape van |
| Tab | map · F3 debug overlay · Esc pause |
| F5 / F9 | quicksave / quickload (saving only while planning — not once the alarm runs) |
| Driving | W/S throttle & brake/reverse, A/D steer, Space handbrake, V camera, R flip |

## Game structure
- **Missions**: heists with wired alarm boxes and a countdown, demolition, sink-it-in-the-harbour, destroy-N%,
  a drone-guarded night job. Optional targets and hidden valuables pay extra.
- **Progression**: score → rank → tool unlocks; cash → ammo upgrades. Saved in localStorage.
- **Sandbox**: any map, all tools, infinite ammo.
- **Tools**: sledgehammer, spray can, extinguisher, blowtorch, handgun, shotgun, planks, cable, pipe bomb, bomb,
  rocket launcher, nitro canister, rifle, leaf blower.
- **Vehicles**: hatchback, van, wheel loader.
- **Security drones**: watchers (alarm after 2 s in sight) and gunners. Indestructible — but not waterproof.
